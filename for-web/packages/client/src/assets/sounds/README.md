# Local sound pack

## Pack fornecido pelo usuário

Os MP3 foram copiados de `Desktop/SFX`, sem alterar o áudio:

| Arquivo original       | Evento no cliente                           |
| ---------------------- | ------------------------------------------- |
| `connect.mp3`          | Entrar na chamada                           |
| `disconnect.mp3`       | Sair da chamada                             |
| `mute.mp3`             | Mutar microfone ou ensurdecer (som privado) |
| `unmute.mp3`           | Reativar microfone ou fone (som privado)    |
| `sharescreen.mp3`      | Iniciar apresentação                        |
| `unsharescreen.mp3`    | Encerrar apresentação                       |
| `screenshare join.mp3` | Outro participante começa a assistir        |
| `screenshare left.mp3` | Outro participante para de assistir         |

Os avisos da chamada e apresentação são reproduzidos localmente por cada
cliente; não são enviados como áudio pelo microfone. A presença dos espectadores
usa o canal de dados da chamada e exige o cliente com esta implementação.
Trocar de renderer ou tela cheia não conta como sair da apresentação.
O som genérico de clique foi removido.

## Tons sintetizados anteriores

Original synthesized tones for this client, generated by
`python scripts/generateUiSounds.py`. No third-party recordings or sound services.
The generated WAV recordings are dedicated to the public domain under CC0-1.0.
That dedication does not apply to the user-provided MP3 recordings above.

Keep the audio files in Git. Vite imports them through the sound controller, so web
and desktop builds include them even when the optional upstream assets are absent.
Playback works without a connection to a sound CDN.
